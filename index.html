Direct AWS Bedrock SDK Call

Calls Amazon Bedrock Runtime directly via the AWS SDK — no API Gateway or Lambda in the path. Great for Node.js backends, CLI tools, or when you control the execution environment. Compare with Tab ① which routes through API Gateway → Lambda → Bedrock.

ℹ
Browser CORS limitation: AWS Bedrock Runtime does not set CORS headers, so direct browser-to-Bedrock calls are blocked. This tab uses mock data in the browser. Enter credentials and copy the Node.js code below to run live extractions without API Gateway or Lambda.
